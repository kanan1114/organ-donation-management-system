ORGAN DONATION MANAGEMENT SYSTEM

Technologies Used:
- Oracle Database XE
- Oracle SQL Developer
- PL/SQL
- Python
- Flask
- HTML
- CSS

Project Features:
- Donor Management
- Recipient Management
- Hospital Records
- Organ Matching
- Dashboard Analytics
- Audit Logging
- Trigger-Based Validation
- Stored Procedures
- Packages and Sequences

How to Run the Project:

1. Start Oracle Database XE.
2. Open SQL Developer.
3. Execute all SQL scripts inside the sql folder.
4. Install required Python packages:
   pip install flask oracledb
5. Run the Flask application:
   python app.py
6. Open:
   http://127.0.0.1:5000
